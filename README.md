# Las 3 Espigas de Oro - Panadería y Bodega

Sitio web para una panadería-bodega ficticia ("Las 3 Espigas de Oro",
San Juan de Miraflores, Lima), adaptado a partir de una plantilla HTML
gratuita como proyecto final del curso **TodoCode**.

## Contenido

- Página de inicio, historia, servicios, menú, reservas, testimonios y contacto.
- Formularios de **suscripción al newsletter**, **reserva de pedidos/tortas** y
  **contacto**, cada uno con validación (incluyendo fechas pasadas en la
  reserva) y mensaje de confirmación en pantalla (sin backend real, pensado
  para funcionar en un hosting estático como GitHub Pages).
- Datos de contacto, menú y testimonios de ejemplo (no corresponden a un
  negocio real).

## Tecnologías

- HTML5 / CSS3 (Bootstrap 4)
- jQuery
- Font Awesome
- Owl Carousel / Tempus Dominus (selector de fecha y hora)

## Créditos

Basado en la plantilla gratuita **KOPPEE - Coffee Shop HTML Template** de
[HTML Codex](https://htmlcodex.com), adaptada y traducida para esta entrega.
Fotografías de [Unsplash](https://unsplash.com).
